# Texto para exercício de manipulação de arquivos

Este arquivo contém um texto genérico para praticar operações com arquivos em Python.

A leitura e a escrita de arquivos são tarefas comuns em programação. Com Python, é possível abrir um arquivo, ler seu conteúdo, adicionar novas informações e salvar alterações.

## Atividades sugeridas

- Ler o conteúdo completo do arquivo.
- Contar as linhas e as palavras.
- Procurar uma palavra específica.
- Adicionar uma nova frase ao final.
- Criar uma cópia com o texto em letras maiúsculas.

---

Use este material para explorar essas operações e observar como cada alteração afeta o arquivo.
